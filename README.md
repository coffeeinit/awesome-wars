## 7. Key Patterns & Lessons

| Pattern | Observation |
|---|---|
| **Wars grow deadlier with technology** | Ancient wars: thousands; Modern wars: millions |
| **Economic cost scales with destruction** | WWI: $332B; WWII: $4T |
| **Civil wars dominate modern conflicts** | 80% of wars since 1945 are internal |
| **Proxy wars fuel regional instability** | Cold War, Middle East |
| **Nuclear weapons changed warfare** | Only used twice; deterrence prevented great power war |
| **Humanitarian crises follow conflict** | Refugees, famine, disease |
| **Peace is fragile** | Many conflicts recur |
